# ADR 0001 — Fronteira n8n / Python / MCP / LLM

**Status:** aceito (herdado do projeto original)

**Decisão:** n8n orquestra canais e retries; domínio Python classifica, resolve unidade e aplica grounding; MCP é a única fonte de fatos; LLM só redige após grounding.

**Consequência:** regra de negócio no canvas do n8n é proibida (backlog A2).
